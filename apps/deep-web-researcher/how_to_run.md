## How to Test the Project

You can run any script in this repo using uv.
For example, to run the main deep research script:

uv run deep_reaserch.py

*Configuration*

Set up from and to email address in email_agent.py
In planner_agent.py, set how many search process you want to be more accurate.

*Notes*

uv run will create/use an isolated environment and install any declared dependencies automatically.
